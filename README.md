# BraiNavLab website

Source code of the website of the BraiNavLab research group at the University of Verona: <https://brainavlab.github.io/>

The site is built with [Jekyll](https://jekyllrb.com/) and published by GitHub Pages at every push on `main`. To update it, see [CURATORS_GUIDE.md](CURATORS_GUIDE.md).
