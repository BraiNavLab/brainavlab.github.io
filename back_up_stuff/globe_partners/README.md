# Globe with the arcs of the real partners

The turning globe of the Network section, in the version with dotted continents and arcs from Verona to the cities of the
partners (`GLOBE_PLACES` at the top of `globe.js`). It was replaced by the version with coastlines and arcs between cities
all over the world, and kept here.

To use it again, copy `globe.js` of this folder over `js/globe.js`. This version does not need d3, so the two d3 scripts
before `js/globe.js` in `index.html` can go too.
